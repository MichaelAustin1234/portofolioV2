## 💻 Panduan Jalankan Lokal

1. **Clone repository & masuk ke direktori**:
   ```bash
   cd potofolioV2
   ```

2. **Install dependensi**:
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan**:
   ```bash
   npm run dev
   ```

4. Buka `http://localhost:3000` pada browser Anda.
